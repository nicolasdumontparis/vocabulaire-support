# Vocabulaire avec Renardo — support

Official support and privacy pages of **Vocabulaire avec Renardo** (iPhone and iPad), served by GitHub Pages:
<https://nicolasdumontparis.github.io/vocabulaire-support/>

- `<lang>/` — support (about, FAQ, contact), `<lang>/privacy.html` — privacy policy, in 13 languages:
  `en`, `fr`, `es`, `pt`, `zh-hans`, `hi`, `ar`, `ru`, `de`, `ja`, `ko`, `it`, `id`.
- `index.html` opens the page in the browser's language (`?choose` shows the list).

The pages are generated: edit `tools/content_a.py` / `tools/content_b.py`, then run `python3 tools/build.py`.
